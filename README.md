# 课堂助手（希沃白板 / Windows 教室大屏）

一个常驻桌面的**纯透明**课堂助手，专为教室一体机设计：

| 功能 | 说明 |
| --- | --- |
| 🎨 双配色文字 | 桌面文字两套配色随时切换：**暖阳金**（金橙渐变，默认，更醒目不单调）/ **经典白**（原来的纯白）；设置里带深色底**实时预览** |
| 📅 事件倒计时 | 屏幕**顶部横版文字**「距离高考还有 250 天 + 目标日期」，支持**多个事件**并排显示；给事件**导入本地图片**后，文字显示在**横版图片卡片**上 |
| 📚 今日课程 | 屏幕**右侧贴紧边框**显示今天的科目（不显示时间）；**已上完的科目自动变暗**，当前课标注「进行中」 |
| 🖥 桌面层显示 | 文字信息**常驻桌面之上、应用之下**：应用不全屏时桌面露出的部分照样可见；切换到桌面**立即显示、无需点击、无延时**（可在设置里改为全局置顶） |
| 🔔 下课提醒 | 一到下课时间，提示从**右上方滑出**，停留 **3 秒**后自动滑走，**没有任何提示音**；**最后一节课**额外显示「**今日课程已上完，辛苦啦喵~**」；**全局置顶** |
| 📌 设置书签 | **蓝色半透明**小书签常驻屏幕**右下四分之一**、贴右边框；**鼠标靠近才滑出**，点击打开设置 |
| 📆 整周课程表 | 设置里是一张**一周课程表**（节次 × 星期），点单元格直接改，一眼看全整周；设置窗口**全局置顶** |
| 🎛 托盘状态 | 右下角托盘图标**实时显示运行状态**（悬停可见“运行中｜高考 250 天”），右键可打开设置/退出 |
| 👻 纯透明 | 除文字与卡片本身外不遮挡桌面；**鼠标完全穿透**，可以直接在希沃白板上书写、点击，不受影响 |

桌面文字默认为**暖阳金渐变**（可切回经典白）：正常/当前课程为高亮色，已上完课程自动变为暗色（亮度可调）。

## 一、快速开始

> 全部文件放同一个文件夹里，不需要安装 Python、Node、.NET SDK 等任何开发环境，
> 只用 Windows 10 / 11 **自带**的 .NET Framework 编译器生成一个绿色 exe。

1. 把整个 `classroom-assistant` 文件夹复制到教室电脑（建议放 `D:\classroom-assistant`，
   不要放 `C:\Program Files` 这类需要管理员权限的目录，否则配置无法保存）。
2. 双击 **`build.bat`** —— 一键编译，成功后同目录出现 `ClassroomAssistant.exe`。
3. 双击 **`run.bat`**（或直接双击 `ClassroomAssistant.exe`）启动。
   启动后没有任何主窗口：屏幕顶部出现倒计时、右侧出现今日科目、屏幕右缘偏下有一枚蓝色小书签，
   右下角托盘区多一个「学」字图标。

第一次运行会自动生成 / 读取同目录的 `config.json`。

```

│                  距离高考还有 250 天                      │ ← 顶部居中
│                   目标日期：2027年6月7日                  │
│                                                        │
│                                        今日课程 · 周三   │ ← 右侧、贴紧边框
│                                             早读        │ ← 已上完：自动变暗
│                                             语文        │ ← 已上完：自动变暗
│                                             数学 进行中  │ ← 当前课：高亮
│                                             英语        │ ← 未上：高亮白
│                                              ……        │   （不显示时间）
│                                                        │
└────────────────────────────────────────────────────────┘
```

**桌面层显示（默认）**：倒计时卡片和课程表位于**桌面之上、普通应用之下**——
应用不全屏时，桌面露出的部分照样能看到文字；切换到桌面**立即显示，无需点击、没有延时**；
任何程序窗口都会自然遮住它们，绝不会盖住课件。
设置里可以改成「文字全局置顶」，改后文字会盖住所有窗口。
**下课提醒**和**设置窗口**始终**全局置顶**，不受此设置影响。

* **设置书签**（蓝色半透明、贴屏幕右缘、位于右下四分之一处）：

```
        屏幕右缘
           │
           │   平时：只露出一条蓝色小边（自动隐藏）
           │   ║
           │   ║
           ├─▶ 鼠标靠近 → 轻轻滑出完整书签（蓝色半透明「设置」）
           │   ║          点击：打开设置界面
           │   ║          右键：打开设置 / 隐藏覆盖层 / 隐藏书签 / 退出
           │
        （屏幕高度 75% 处，即右下四分之一的中心）
```

* **下课提醒**（右上角，纯文字，3 秒后滑走）：

```
                                    ┌────────────────────────┐
                                    │ 下课提醒                │
                                    │ 语文（第二节 08:55 - 09:40）已结束 │
                                    │ 下一节：数学  10:00 开始   │

```

> 想让提示带一块半透明深色底（更好看清），在设置里勾选
> 「下课提示使用半透明背景」即可；默认是纯文字，严格不遮挡桌面。

## 三、设置界面

两种打开方式，任选其一：

| 入口 | 操作 |
| --- | --- |
| 📌 屏幕右缘的蓝色书签 | 鼠标**靠近**右侧边缘滑出书签，**左键点击**打开；**右键**是快捷菜单 |
| 🎛 右下角托盘图标 | **双击**打开设置，或**右键 → 设置** |

设置界面长这样（顶部彩色标题栏 + 卡片分组；节次 × 星期的整周课程表，单元格直接点开改）：

设置窗口里可以改：

1. **倒计时卡片**：一张表管理**任意多个事件**（显示 / 事件名称 / 目标日期 / 背景图片）；
   点「选择背景图片…」可**从本地导入图片作为卡片背景**（留空 = 纯文字卡片），
   「显示」列打勾的才会出现在桌面顶部；底部实时预览倒计时效果。
2. **一周课程表**：左边三列是**节次名 / 开始 / 结束**，右边七列是**周一到周日**上的科目；
   **留空 = 当天没有这节课**。点「添加节次 / 删除选中节次」可以增减行；
   保存时会自动按开始时间排序，整行都空的行会被清掉。
3. **外观**：**文字样式**（暖阳金 / 经典白，两个版本随时切换）、字体大小（70%–180%）、
   已上完课程的亮度（暗色深浅）、下课提示底色开关、**文字全局置顶**开关（默认关闭 = 桌面层显示）。
4. **其他**：开机自动运行；是否显示右侧「设置」书签。

点「保存」立即生效并写入 `config.json`。

## 四、`config.json` 字段说明

也可以直接用记事本编辑（编辑后在托盘菜单选「重新加载配置」）：

```json
{
  "FontScale": 1,                // 字体缩放，1 为默认大小
  "DimOpacity": 0.25,            // 已上完课程的亮度（0.08 ~ 0.5，越小越暗）
  "ToastPanel": false,           // 下课提示是否带半透明底色
  "ShowBookmark": true,          // 是否显示右侧「设置」书签
  "TextTopmost": false,          // 文字全局置顶（默认 false = 桌面之上、应用之下）
  "TextStyle": "gold",           // 文字样式：gold = 暖阳金渐变（默认），white = 经典白
  "Events": [                    // 倒计时卡片，可放任意多张
    {
      "Name": "高考",             // 事件名称
      "Date": "2027-06-07",      // 目标日期 yyyy-MM-dd
      "Image": "D:\\图片\\高考.jpg",  // 背景图片（本地路径），留空 = 纯文字卡片
      "Enabled": true            // false = 不显示这张卡片
    }
  ],
  "Periods": [                   // 一周课程表：一行 = 一个节次
    {
      "Label": "第一节",          // 节次名
      "Start": "08:00", "End": "08:45",
      "Mon": "语文", "Tue": "语文", "Wed": "数学",
      "Thu": "语文", "Fri": "语文", "Sat": "", "Sun": ""
    }
  ]
}
```

* 一周七天各一列（`Mon`…`Sun`），**留空表示当天没有这节课**。
* 文件必须是标准 JSON（**不能有 `//` 注释**）；格式写错时程序会弹窗提示并先用默认课表顶上，不会悄悄丢失。
* 旧版配置（单个 `EventName`/`EventDate`、每天一列课程的 `Schedules`）会被**自动转换**并写回新格式，
  转换后请到设置里核对一遍。

## 五、希沃一体机部署建议

1. **开机自启**：设置里勾选「开机自动运行」，或把 `run.bat` 的快捷方式放进
   `shell:startup` 文件夹。这样每天开机会自动出现在桌面。
2. **不影响教学**：覆盖层窗口设置了 `WS_EX_TRANSPARENT`（鼠标穿透）+ `WS_EX_NOACTIVATE`（不抢焦点），
   在希沃白板上书写、点击、拖动完全不受影响；它也不会出现在任务栏和 Alt+Tab 里。
   书签标签**可以点击**，但同样不抢焦点。
3. **多屏 / 分辨率 / 缩放**：自动铺满整个屏幕（含 4K、125%/150% 系统缩放），插拔显示器后自动重新适配。
4. **改课表**：直接在设置的整周课程表里改，保存后立即生效；临近期末换考试安排时也可以随时改事件名称和日期。
5. **测试下课提醒**：在命令行运行 `ClassroomAssistant.exe --testtoast`（普通下课）或
   `ClassroomAssistant.exe --testtoast-last`（最后一节课），立刻弹出一次完整提示效果。
6. **异常排查**：在命令行里运行 `ClassroomAssistant.exe --selftest`，会在程序目录生成
   `selftest.log`（自检过程，含课程状态判定和桌面层挂载情况）、`selftest-overlay.png`（桌面覆盖层快照，
   可直接看到高亮/变暗效果）和 `selftest-settings.png`（设置界面快照），把这三份发给维护老师即可定位问题。

## 六、常见问题

**Q：为什么我点不到屏幕上的文字？**
正常。倒计时、今日课程、下课提示这些界面鼠标完全穿透，为的就是不干扰白板操作。
要操作程序请把鼠标**移到屏幕右缘偏下**，蓝色书签会滑出来，点它即可；或用右下角托盘图标。

**Q：打开课件 / 软件后，倒计时和课程表不见了？**
正常。它们位于**桌面之上、应用之下**：程序窗口会自然遮挡它们；应用不全屏时，
桌面露出的部分照样可见；回到桌面**立即显示，无需点击、没有延时**。
下课提醒和设置窗口不受影响，始终置顶。

**Q：右下角看不到托盘图标 / 看不到运行状态？**
Windows 11 会把新图标收进**托盘溢出区**：点任务栏右侧的 **^** 就能看到“学”字图标，
**鼠标悬停**即可看到运行状态（如「课堂助手 · 运行中｜高考 250 天」），右键可打开设置 / 退出。
想让它常驻任务栏：任务栏空白处右键 → 任务栏设置 → 其他系统托盘图标 → 把“课堂助手”打开。

**Q：设置界面点不动 / 修改了存不上？**
这是**提示框被别的窗口挡住**造成的“假死”（程序其实在等一个看不见的对话框）。新版已修复：
**所有提示框强制置顶显示**，不会再被设置窗口、浏览器或课件盖住。
如果确实保存失败，多半是**程序目录只读**（例如装在 `C:\Program Files`）——
把整个文件夹移到 `D:\classroom-assistant` 这类可写目录即可；新版还会**自动改存到当前用户目录**
（`%APPDATA%\ClassroomAssistant\config.json`）并明确告诉你保存位置。

**Q：点「保存」提示“保存失败：不允许所请求的注册表访问权”？**
**设置本身已经保存成功**，只是「开机自动运行」没设置上（系统策略限制了注册表写入）。
开机自启可以手动做：把 `run.bat` 的快捷方式放进 `shell:startup` 文件夹。
新版已把“注册表写入”和“保存设置”分开处理，注册表失败**不会**再影响设置保存。

**Q：想让文字盖住所有窗口（比如演示时）？**
设置 → 外观 → 勾选「**文字全局置顶**」→ 保存。默认不勾：文字只在桌面层显示。

**Q：想试试下课提醒长什么样？**
在命令行运行 `ClassroomAssistant.exe --testtoast`（普通下课）或
`ClassroomAssistant.exe --testtoast-last`（最后一节课，带「今日课程已上完，辛苦啦喵~」）：
立刻弹出一次示例提示（右上滑入 → 停留 3 秒 → 滑走，无声音），不需要先启动课堂助手，可反复测试。

**Q：书签平时看不太清 / 被我隐藏了？**
书签平时只在屏幕右缘露出一条蓝色细边（自动隐藏），鼠标靠近才滑出完整标签。
被隐藏后：右下角托盘图标（双击）→ 设置 → 勾选「在屏幕右侧显示设置书签」→ 保存。

**Q：桌面右侧的科目想显示时间？**
目前按需求只显示科目名。需要显示时间的话告诉我，我把时间列加回成可选项。

**Q：想换成「距离中考 / 期末考试还有 N 天」？**
托盘或书签 → 设置 → 把事件名称和目标日期改掉，保存即可。

**Q：某天的课不一样（如周三下午放假）？**
在课程表里把周三那几个单元格**清空**即可，留空 = 当天没有这节课。

**Q：下课提醒为什么没有声音？**
按需求设计为完全静音，只做视觉提示。

**Q：编译报错怎么办？**
确认是 Windows 10 / 11（自带 .NET Framework 4.x）；把 `build.bat` 窗口里的错误信息复制下来反馈。
